1. What does Brain do? Why: whole spec. Status: answered. Answers-by: P3 code. Answer: a sound toy: 1-9 simultaneous slots, four panning modes, random wavs at random pitch until a key (GAME_SPEC 1, 3). The original is not run (item 15), so no owner observation follows. Tag: CODE. Session: P3 S3.1.
2. How are the wavs played? Why: sound layer. Status: answered. Answer: DirectX 8 for VB DirectSound buffers, not SAPI; DirectX named only by class ID (GAME_SPEC 2). Tag: CODE. Session: P3 S3.1.
3. Are the wavs counted and picked at random? Why: pool logic. Status: answered. Answer: n = files matching brain*.wav in the current folder (1 if none); number = Int(n * Rnd) + 1; FileLen gives the size for the cut-off (GAME_SPEC 5.2, 5.4). Tag: CODE. Session: P3 S3.1.
4. Does Brain launch gamemenu.exe? Why: exit flow. Status: answered. Answer: yes, on exit if Dir finds it in the current folder, Shell style 3, nothing spoken; otherwise " exiting program ", two beeps, a message that is never heard (GAME_SPEC 3.5). gamemenu is its own project. Tag: CODE. Session: P3 S3.1.
5. Is nobrain.bat available? Why: brain.txt mentions it. Status: answered. Answer: no; not needed, the installer gives a normal uninstaller. Tag: OWNER-CONFIRMED. Session: after P3 S3.1.
6. Is brain7.wav (silent) deliberate? Why: wav handling. Status: answered for the clone. Answer: picked like any other wav, a short silent turn; the clone plays it as it is; the author's intent is not needed. Tag: CODE. Session: P3 S3.1.
7. When are the two message boxes shown? Why: errors. Status: answered. Answer: no-voices box at startup when SAPI has no voices, then exit; corrupt-wave box unreachable (On Error Resume Next). Title "brain" (VB header strings, P5). Clone no-voices behavior: GAME_SPEC 15. Tag: CODE. Session: P3 S3.1, title P5 S5.2.

9. What are keys 1-9 for? Why: menu. Status: answered. Answer: number of sound slots playing at once (GAME_SPEC 5.1). Tag: CODE. Session: P3 S3.1.
10. How is panning done? Why: sound layer. Status: answered. Answer: DirectSound SetPan, table -750..750 in 11 steps, mode 4 random -1000..990 (GAME_SPEC 5.5). Tag: CODE. Session: P3 S3.1.
11. Randomize and Rnd use (5.5)? Why: faithful randomness. Status: answered. Answer: Randomize Timer at each playback start; 20 Rnd call sites in the program (9 slots x 2 for number and pitch, plus modes 3 and 4); the clone matches ranges, not sequences (GAME_SPEC 6). Tag: CODE. Session: P2 review, P3 S3.1, call-site wording P5 S5.2.

24. What do voices say for unusual keys in the main menu echo? Why: speech fidelity. Status: answered. Answers-by: P5 test. Answer: the voice gets LCase(Chr(KeyCode)) (code page 1252) with Speak flags 0. Tested with voice 0 FlexVoice2 Bill and Microsoft David (`games/tools/sapi_key_echo.ps1`, `work/p5_key_echo.tsv`): many keys are silent on both (Enter, Space, Tab, Shift, Page Up and Down, Right and Down arrows, Insert, Delete, F12 ...); End, Home, Left and Up arrows speak "#", "$", "%", "&"; F1-F11 speak the letters p-z; numpad digits the letters a-i; some punctuation keys depend on the voice (GAME_SPEC 8.2). The clone sends the same characters to the same voice with the same flags, so the result is the same by construction; the P8 listen is an optional confirmation only. Tag: CODE plus test.
